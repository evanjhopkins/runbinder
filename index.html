How it works

Definition in the repo. State on the server.

RunBinder keeps schedules portable without making runtime state part of your project.

01

Define

Write the command, working directory, and schedule in a YAML file beside your code.

02

Register

Bind a validated snapshot locally, then manage the task by namespace from any directory.

03

Run

Use one service for schedules, bounded concurrency, run history, logs, and overlap protection.

Right-sized orchestration

Lightweight task scheduling for projects that run directly on a server. Natural for solo work and useful for teams that want straightforward production jobs to stay straightforward.

Get started

One command. One binary.

Install with Go 1.24 or newer, then run runbinder init inside a project.

go install github.com/evanjhopkins/RunBinder/cmd/runbinder@latest
